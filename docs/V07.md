# V0.7 — Product Foundation

V0.7 turns UNLOOP from an API-first prototype into the beginning of the actual product.

## Included

- Real local web app at `/`.
- Streaming-service selector with Spotify as the first working adapter.
- Apple Music, Navidrome and Local Library represented as planned provider slots.
- Finite-batch UI: no infinite feed and no swipe interface.
- Custom playlist naming; a blank name keeps the default `UNLOOP Discovery`.
- Provider-status API at `/v1/streaming-services`.
- Product manifesto hardened around no swiping, no doomscrolling and time-efficient discovery.
- Fixed recommendation-history persistence in `DiscoveryService.generate`.

## Next

- Apple Music provider investigation/adapter.
- Playback handoff buttons per track.
- Feedback controls in the product UI.
- Source and discovery analytics views.
- Mobile-friendly core boundary for Android/iOS clients.
