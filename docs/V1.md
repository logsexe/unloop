# UNLOOP V1 Developer Preview

V1 is the first end-to-end milestone where the native Android client can drive the real UNLOOP discovery engine.

## Product contract

UNLOOP exists to improve music discovery without becoming another attention product.

V1 preserves these non-negotiables:

- no swipe-to-discover feed;
- no infinite scroll;
- no streaks or FOMO mechanics;
- no ads;
- no sponsored recommendations;
- no paid ranking;
- no engagement-maximising notifications;
- finite discovery batches only.

The desired interaction is:

```text
connect service
    ↓
choose discovery intent
    ↓
create finite batch
    ↓
save/open playlist
    ↓
leave UNLOOP
```

## V1 capabilities

### Discovery engine

- Spotify history and playlist publishing;
- ListenBrainz collaborative candidates;
- MusicBrainz enrichment;
- novelty and artist-saturation scoring;
- recommendation memory;
- feedback and artist cooldowns;
- language, relatability, era, genre and explicit-content controls;
- custom playlist naming;
- local SQLite persistence;
- batch analytics.

### Android client

- Jetpack Compose native UI;
- configurable UNLOOP engine URL;
- engine health check;
- Spotify connected/not-connected state;
- Spotify OAuth browser handoff;
- Safe / Explore / Deep Cut / Chaos selection;
- 15 / 30 / 45-track finite batches;
- language and relatability controls;
- genre/scene seed;
- custom/default playlist name;
- playlist creation;
- streaming-app handoff after completion.

## Architecture for the preview

```text
Android client
      │
      │ HTTP on trusted local network (developer preview)
      ▼
UNLOOP Python engine
      │
      ├── Spotify
      ├── ListenBrainz
      └── MusicBrainz
```

This boundary is intentional. It gets the real product onto a phone quickly while keeping the discovery core independent from any one mobile platform. The engine can later move on-device without redesigning the product workflow.

## Not production-complete

V1 Developer Preview does not claim public-store readiness. Remaining work includes:

- HTTPS for non-local networking;
- secure persistent mobile credentials;
- direct callback/deep-link handling on mobile;
- richer native results and feedback controls;
- offline/on-device discovery-core strategy;
- Apple Music provider;
- Navidrome provider;
- accessibility and localisation review;
- release signing and reproducible build work;
- iOS client.

## Success criteria

V1 is successful when a tester can start UNLOOP on a computer, install/open the Android client, connect Spotify, create a filtered finite discovery playlist from the phone, open that playlist, and leave the app.

The metric is not session length. The metric is useful new music found per minute spent discovering.
