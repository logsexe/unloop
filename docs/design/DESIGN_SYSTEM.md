# Design system principles

UNLOOP's visual system should communicate calm control.

## Layout

- 8pt spacing grid.
- 16–24dp card padding.
- Minimum 48dp touch targets.
- Finite lists with visible item count.
- Album art should never overpower recommendation rationale.

## Type hierarchy

- Display: discovery mode / primary moment.
- Title: track or section title.
- Body: recommendation rationale.
- Label: metadata and controls.

Avoid excessive uppercase except small functional labels.

## Motion

Motion communicates state transitions only. Avoid looping animation, shimmer intended to retain attention, or celebratory animations for ordinary engagement.

## Accessibility

- WCAG-conscious contrast.
- Dynamic type support.
- Do not communicate score/reason by colour alone.
- Screen-reader labels for all playback and feedback controls.
- Reduce-motion support.
